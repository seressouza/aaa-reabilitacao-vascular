# Glossário

[← Índice](README.md)

| Termo | Significado |
|---|---|
| **AAA** | Aneurisma de aorta abdominal: aorta abdominal ≥ 3,0 cm |
| **Infrarrenal** | Abaixo das artérias renais; localização mais comum do AAA |
| **Fusiforme** | Dilatação em forma de fuso, simétrica, de toda a circunferência da aorta |
| **Trombo mural** | Camada de trombo aderida à parede interna do aneurisma |
| **Open repair** | Correção aberta: laparotomia ou acesso retroperitoneal e enxerto |
| **EVAR** | *Endovascular aneurysm repair*: endoprótese colocada por via femoral |
| **Endoleak** | Fluxo de sangue persistente para dentro do saco aneurismático após EVAR |
| **Síndrome pós-implante** | Febre e mal-estar inflamatórios nos primeiros dias após EVAR |
| **Pseudoaneurisma** | Coleção de sangue pulsátil fora da artéria, no local da punção |
| **Permissive hypotension** | Manter a pressão abaixo do normal até controlar o sangramento na rotura |
| **ERAS** | *Enhanced Recovery After Surgery*: protocolos de recuperação acelerada |
| **Prehabilitation** | Pré-habilitação: exercício e otimização antes da cirurgia |
| **SET** | *Supervised exercise training*: treino com exercício supervisionado |
| **DAP / PAD** | Doença arterial periférica |
| **CLTI** | *Chronic limb-threatening ischaemia*: isquemia crônica com ameaça ao membro |
| **Bypass infrainguinal** | Ponte arterial abaixo da virilha (femoropoplítea, femorodistal) |
| **Síndrome compartimental pós-reperfusão** | Aumento da pressão nos compartimentos musculares após restaurar o fluxo; emergência cirúrgica |
| **Valsalva** | Expiração forçada com glote fechada; eleva muito a pressão arterial e intra-abdominal |
| **1RM** | Uma repetição máxima: a maior carga levantada uma única vez |
| **Borg 11–13** | Esforço percebido "relativamente fácil" a "ligeiramente cansativo" na escala 6–20 |
| **Classe / Nível** | Força da recomendação (I a III) / qualidade da evidência (A a C) |
